 ### CodeAlpha C Programming Tasks

Welcome to my CodeAlpha Internship project repository!

This repository contains the C programming tasks I completed as part of my internship. The projects focus on fundamental and practical concepts of C programming.

 Tasks

### Task 1 – Smart Calculator
A menu-driven calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power

**Concepts:** `switch case`, loops, functions, arithmetic operations.

 ### Task 2 – Matrix Operations
A program to perform:
- Matrix Addition
- Matrix Multiplication
- Matrix Transpose

**Concepts**: functions, 2D arrays, loops and modular programming.

### Task 3 – Smart Student Record Hub
A menu-driven student management system with:
- Add Student
- Delete Student
- Update Student
- Search Student
- Display Records
- Automatic Grade & Pass/Fail calculation
- Permanent file storage

**Concepts:** structures, functions, file handling, searching and loops.

---

### Task 4 – Smart Banking System
A mini banking management system with:
- Create Account
- Deposit Money
- Withdraw Money
- Balance Enquiry
- Search Account
- Transaction History
- Display All Accounts
- Permanent file storage

**Concepts:** structures, functions, file handling, validation and menu-driven programming.
